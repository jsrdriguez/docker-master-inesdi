# Instrucciones

Renombrar el fichero 
### `.env.example a .env`


Ejecutar en la raiz de proyecto: 
### `./deploy.sh`

En la carpeta test se encuentra, registro de pruebas
con su respectiva imagen para probar la web y verificar 
el uso de los volumenes.

Para borrar los contenedores creados:

### `./clean.sh`

En la carpeta screenshots se encuentra las imagenes de las pruebas realizadas
